# Official-repository packages only (pacman). One per line; text after '#'
# is a comment. NO AUR packages are required, so nothing here is ever built
# from user-submitted PKGBUILDs.
#
# Name verification status:
#   Confirmed on archlinux.org by search: quickshell, hyprland, hyprlock,
#   hyprpolkitagent, cliphist, wl-clipboard, tree-sitter-cli.
#   The rest (including ghostty, nautilus, btop, jq, dconf, sddm, mesa) are standard
#   Arch names but were NOT individually confirmed.
#   Plain Arch installs very little, so this list also carries the basics a
#   desktop needs (graphics driver, fonts, login screen). Anything already
#   installed is skipped by `pacman -S --needed`.
#   install.sh runs `pacman -Si` on every name first and reports unknown ones
#   instead of failing halfway through an install.

# --- Base for a graphical session (plain Arch has none of this) ---
mesa                # OpenGL/Vulkan drivers; Intel iGPU and virtio-gpu in a VM
sddm                # graphical login screen (install.sh does NOT enable it; see docs/installation.md)
noto-fonts          # fallback glyphs
xdg-user-dirs       # ~/Pictures, ~/Downloads etc.

# --- Desktop core ---
hyprland            # compositor / window manager
hypridle            # idle daemon
hyprlock            # screen locker
hyprpolkitagent     # polkit authentication agent (privileged actions)
quickshell          # desktop shell (also provides the `qs` command)
polkit
xdg-desktop-portal-hyprland
xdg-desktop-portal-gtk
qt6-wayland

# --- Terminal and shell ---
ghostty
zsh
zsh-autosuggestions
zsh-syntax-highlighting
ttf-jetbrains-mono-nerd

# --- Apps ---
nautilus            # file manager (GNOME Files, as on Ubuntu)
btop                # system monitor (replaces a dashboard)
mpv                 # media player (configured to match Omarchy)

# --- Utilities used by keybindings and Quickshell ---
wl-clipboard        # wl-copy / wl-paste
cliphist            # clipboard history
grim                # screenshots
slurp               # region / window selection
jq                  # reads window list for window screenshots
dconf               # lets gsettings (dark theme) persist
brightnessctl
playerctl
libnotify           # notify-send

# --- Services Quickshell talks to over D-Bus ---
pipewire
wireplumber         # provides wpctl
networkmanager      # provides nmcli
bluez
bluez-utils         # provides bluetoothctl
upower

# --- Development (Neovim + systems programming) ---
neovim
git
base-devel
clang               # clangd, clang-format
lldb                # provides lldb-dap
gdb
cmake
ninja
bear                # compile_commands.json for Makefile projects
tree-sitter-cli
ripgrep
fd
